# Portfolio

이 페이지는 제가 진행한 프로젝트와 학습 기록 중에서 대표적인 내용을 정리하는 공간입니다.

블로그 전체 글은 학습 기록에 가깝고, 이 페이지는 그중에서 포트폴리오로 보여줄 만한 내용을 모아두는 역할을 합니다.

## 대표 프로젝트

### UECADA Digital Twin Project

Unreal Engine 기반으로 제조 설비 상태를 시각화하는 디지털 트윈 대시보드 프로젝트입니다.

#### 담당 역할

- UMG 기반 대시보드 UI 제작
- OEE, UPH, ESG 카드 구현
- 설비 상세 정보 위젯 구성
- Blueprint 기반 기능 구현
- Git / GitHub 협업 및 충돌 해결

#### 사용 기술

- Unreal Engine
- Blueprint
- UMG
- Git / GitHub
- GitHub Pages
- Jekyll / Chirpy

#### 주요 구현 내용

- 설비별 상세 카드 UI 제작
- OEE 카드 데이터 표시 구조 구성
- UPH 차트 UI 구성
- ESG 운영현황 카드 구성
- Web Browser 기반 영상 표시 영역 구성
- 설비별 URL 관리 구조 설계

#### 관련 글

아직 관련 글을 작성하지 않았습니다.  
프로젝트 정리 글을 작성한 뒤 이곳에 링크를 추가할 예정입니다.
